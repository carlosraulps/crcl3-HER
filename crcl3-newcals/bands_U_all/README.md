# CrCl3 (2x2) Band Structures with U_all = 3.29 eV (`bands_U_all`)

This directory contains the electronic band structure calculations along the high-symmetry path $\Gamma \to \mathrm{M} \to \mathrm{K} \to \Gamma$ under PBE+D3(BJ) with Dudarev Hubbard $U = 3.29\text{ eV}$ applied to ALL transition metal species ($U_{\text{Cr}} = 3.29\text{ eV}$, $U_{\text{TM}} = 3.29\text{ eV}$).

---

## 📌 Site Provenance

* **`adsorbed/Co`**: **Site S3 (Top-Cr)**
  - Co located at $(x,y) = (0.667, 0.333)$ ($\Delta z_{\text{Co-Cr}} = +2.58\text{ \AA}$).
* **`adsorbed/Fe`**: **Pore-Penetrated Ground State**
  - Fe located at $(x,y) = (0.500, 0.498)$ inside the pore ($\Delta z_{\text{Fe-Cr}} = +0.17\text{ \AA}$).
* **`adsorbed/Ni`**: **Pore-Penetrated Ground State**
  - Ni located at $(x,y) = (0.500, 0.500)$ inside the pore ($\Delta z_{\text{Ni-Cr}} = +0.28\text{ \AA}$).

* **`embedded/*`**: **In-Plane Interstitial**
  - Co, Fe, Ni embedded in the monolayer interior, coplanar with the Cr plane ($\Delta z_{\text{TM-Cr}} \approx 0.00\text{ \AA}$).
